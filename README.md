# VIDEO_TO_ASCII

A small GitHub Pages project that converts a video selected by the visitor into animated ASCII text in the browser.

## Run locally
Open `index.html` in a modern browser. Choose a video, then press **PLAY**.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` (you can also upload this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub to provide your website URL.

The selected video is processed locally in the browser; it is not sent to a server.
